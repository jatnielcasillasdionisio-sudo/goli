[LANGUAGE PARADIGMS & GUIDELINES]

1. C++ (Modern C++20 / C++23):
   - Strict RAII (Resource Acquisition Is Initialization) for all resource management.
   - Zero raw `new` / `delete`. Enforce `std::unique_ptr`, `std::shared_ptr`, and `std::span`.
   - Prefer `constexpr`, `consteval`, concepts (`template <typename T> requires ...`), and `std::move` semantics.
   - Cache-conscious data structures; minimize dynamic memory allocations in the hot path.

2. Rust (2021+ Edition):
   - Idiomatic ownership and borrow checker mastery. Avoid unnecessary `.clone()` calls.
   - Use `Arc<T>`, `Mutex<T>`, `RwLock<T>` safely. Prefer channel passing (`crossbeam`, `tokio::sync::mpsc`).
   - Trait-driven design, dynamic dispatch only where polymorphic extensibility outweighs vtable cost.
   - Unsafe blocks must have explicit `// SAFETY:` rationale and sound invariants.

3. Go (1.22+):
   - Clear concurrency with Goroutines, sync.Pool, sync.Mutex, and buffered channels.
   - Context propagation (`ctx context.Context`) through all I/O, network, and RPC boundaries.
   - Struct memory layout optimization (field ordering by word size to minimize struct padding).
   - Zero-copy techniques: `unsafe.SliceData`, `bytes.Buffer`, `sync.Pool` allocation reuse.

4. Python (Modern 3.12+):
   - Strict typing with `typing` and `mypy` compliance.
   - Generator pipelines (`yield`), asynchronous event loops (`asyncio`), and vectorization.
   - Slots (`__slots__`) for memory-intensive classes. Avoid mutable default arguments.

5. TypeScript (Modern 5.x+):
   - Strict null checks, branded types, discriminated unions, and exhaustiveness checking (`never`).
   - Immutability where practical (`readonly`, `as const`), functional composition, and defensive parsing (Zod).
